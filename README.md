## 🎨 Features & Highlights

- **✨ Modern & Immersive Design:** Deep layered dark themes (`#05070f` to `#0e1424`) with smooth mesh background gradients and micro-interactions.
- **📱 Responsive Layout:** Perfectly optimized for mobile, tablet, and desktop screens with dynamic mobile-first navigation and custom styling.
- **✉️ Fully Functional Contact Form:** Integrated with [Web3Forms](https://web3forms.com/) (delivering client inquiries directly to Gmail inbox instantly).
- **💡 Interactive Skill Bars:** Custom JetBrains Mono-styled percentage indicators that animate as you scroll.
- **🛠️ Projects Section:** Detailed showcase cards featuring interactive overlays, tech tags, and links to source code/live previews.

## 🚀 Local Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/bhusanbibhuti2005/Bibhuti-Portfolio.git
   cd Bibhuti-Portfolio
   ```

2. **Run Locally:**
   Simply double-click `index.html` or run it using a local dev server:
   ```bash
   # If you use VS Code, right-click index.html and choose "Open with Live Server"
   # Or run via Python:
   python -m http.server 8000
   ```

3. **Firebase Deployment:**
   To deploy updates to the web:
   ```bash
   firebase deploy --only hosting
   ```
